# DoraPresentationTimer

プレゼンテーションの残り時間を、拍子木と銅鑼の音で知らせるシンプルなカウントダウンタイマーです。iPhone / iPad と Apple Watch に対応し、iOS 版では外部ディスプレイにも残り時間を表示できます。

## 主な機能

- カウントダウンの開始、一時停止、リセット
- 2つのリマインド時刻と、終了時の銅鑼
- アプリが画面外にある場合にも知らせるローカル通知
- タイマー実行中の自動スリープ防止（iOS）
- Apple Watch でのタイマー操作、音、触覚フィードバック
- 外部ディスプレイへの残り時間表示（iOS）
- システム / ライト / ダークの表示モード
- 日本語、英語、簡体字中国語、韓国語、スペイン語
- VoiceOver 向けのラベル、ヒント、残り時間の読み上げ
- 設定の端末内保存

## 対応プラットフォーム

- iOS / iPadOS 26.0 以降
- watchOS 26.0 以降

## 使い方

1. 残り時間の表示をタップし、発表時間を設定します。
2. **Start** をタップするとカウントダウンが始まります。
3. 設定したタイミングで拍子木が鳴り、終了時に銅鑼が鳴ります。
4. **Pause** で一時停止し、もう一度 **Start** を押すと再開します。

初回の開始時に通知が求められます。許可すると、アプリが画面外にある場合もリマインドと終了をローカル通知で受け取れます。

### Reset の挙動

- 1回目: 設定した発表時間に戻します。
- 2回目: `0:00` にクリアし、保存されている発表時間も `0:00` にします。

タイマーの実行中は Reset と時間の変更を行えません。

## 設定

iOS 版の歯車ボタンから、次の項目を変更できます。

- 発表時間
- 1回目 / 2回目のリマインド時刻
- リマインド音の試聴
- 表示モード（システム / ライト / ダーク）
- 表示言語

リマインドは「終了何秒前に鳴らすか」で指定します。発表時間を超える値は発表時間までに補正され、終了時刻と銅鑼は `0` 秒に固定されます。実行中に保存済み設定が変わっても、進行中のタイマーでは開始時のリマインド設定を使います。

Apple Watch 版では、発表時間、2つのリマインド時刻、表示言語を本体上で設定できます。設定は iOS 版と自動同期せず、それぞれのアプリ領域に保存されます。

## 外部ディスプレイ

iPhone / iPad を外部ディスプレイやプロジェクターに接続すると、タイマー画面に接続中ボタンが表示されます。そこから次の項目を調整できます。

- 外部ディスプレイの背景色
- 残り時間を表示するかどうか

外部ディスプレイには操作 UI を出さず、プレゼンテーション向けの表示だけを出力します。

## プロジェクト構成

```text
DoraPresentationTimer/
├── Shared/
│   ├── Core/                  # タイマー、音声、通知
│   ├── Features/
│   │   ├── Settings/          # 設定モデル、保存、設定画面
│   │   └── Timer/             # タイマー画面、状態管理、ルール
│   └── Resources/             # 音声、フォント、画像、ローカライズ
├── iOS App/
│   ├── ExternalDisplay/       # 外部ディスプレイ表示と設定
│   └── Launch/                # アプリとシーンのライフサイクル
└── Watch App/                 # watchOS アプリのエントリーポイント
```

共有コードを iOS / watchOS の両ターゲットから利用し、プラットフォーム固有の画面とライフサイクル処理だけを各 App ディレクトリに分けています。

## 技術構成

- Swift（Swift 5 言語モード）
- SwiftUI
- Observation（`@Observable`）
- Swift Concurrency（`Task` / `AsyncStream`）
- AVFoundation
- UserNotifications
- UIKit / WatchKit（プラットフォーム固有機能）

タイマーは開始時の終了予定時刻から残り時間を逆算するため、画面更新が一時的に止まっても経過時間とのずれを抑えます。

## データ保存とプライバシー

- アカウント登録なし
- 外部サーバーとのネットワーク通信なし
- 広告 SDK・分析 SDK なし
- 設定は iOS アプリと Watch アプリそれぞれの `UserDefaults.standard` に保存（端末間の自動同期なし）
- 通知は端末内でスケジュールされるローカル通知のみ

## 開発・ビルド

1. `DoraPresentationTimer.xcodeproj` を Xcode で開きます。
2. `DoraPresentationTimer` または `DoraPresentationTimerWatch Watch App` スキームを選択します。
3. 対応するシミュレータまたは実機を選び、Run します。

音声ファイルとフォントはリポジトリ内の `Shared/Resources` に含まれています。
